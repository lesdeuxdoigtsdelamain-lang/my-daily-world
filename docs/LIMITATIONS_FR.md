# Limites explicites

1. **Mise en service externe** : sans dépôt GitHub autorisé, Pages activé et adresses configurées, l’APK lit l’édition réelle incluse et les téléchargements déjà faits. Il ne peut pas créer un compte ou déployer sur votre compte absent. Cloudflare réel exige les deux secrets exclusivement saisis chez GitHub.
2. **Horaires** : préparation 15:20 UK et reprise 16:15 ; une exécution supplémentaire à 17:00 génère l’édition si elle manque, sans remplacer une édition validée. Rappel souhaité 17:00. GitHub, Doze, batterie Samsung et permissions peuvent retarder l’ensemble. Le programme ne garantit pas une livraison exacte. Aucun PC permanent n’est requis. Réactivation parfois nécessaire après 60 jours d’inactivité.
3. **Sources et droits** : les flux qui répondent ne donnent pas automatiquement un droit de redistribution / transformation IA. Les connecteurs BBC, Sky et Al Jazeera restent désactivés par défaut après examen de leurs conditions. Ils ne deviennent actifs qu’après établissement des droits appropriés, sans abonnement imposé par ce logiciel. Le journal par défaut combine les sources réutilisables documentées ; les annonces officielles sont attribuées et ne remplacent pas un média indépendant. La couverture peut être plus restreinte, et aucune rubrique n’est remplie artificiellement.
4. **Validation des faits** : aucun programme déterministe fondé sur les seuls noms, nombres et citations ne peut prouver une paraphrase libre. Cette version rejette donc toute phrase IA qui n’est pas une phrase de preuve complète. L’IA sélectionne / organise des phrases sourcées ; elle ne dispose pas d’une autorisation de publier des ajouts narratifs. Les récits controversés restent de courts titres attribués. Les sources peuvent elles-mêmes se tromper. Aucune promesse de vérité parfaite ou de filtrage linguistique infaillible.
5. **Longueur** : souvent `compact`, particulièrement sans IA ou avec des RSS peu détaillés. `full` exige 7–10 sujets, cinq questions et 80–115 mots de résumé par sujet. La durée réelle est calculée, jamais fixée artificiellement à 8–10 minutes. L’édition peut être absente si aucun élément sûr n’est disponible.
6. **Quiz** : exercices déterministes de lecture des titres à compléter. Jusqu’à cinq questions ; moins si les preuves / distracteurs distincts manquent. Pas de quiz factuel inventé à partir d’un contexte implicite.
7. **Histoire** : 33 anniversaires cités ; aucune revendication de couverture de 366 jours. Les années sont postérieures à 1582 pour éviter des conversions historiques julien / grégorien douteuses. Voir les instructions d’extension.
8. **Niveaux de lecture** : ajustement local de présentation, mêmes faits pour tous. Pas de profil d’enfant envoyé au serveur, ni de réécriture individualisée.
9. **Gratuité** : GitHub public + runners standards + Pages et Workers Free. Limite documentée 10 000 neurons/jour partagés entre les usages du compte. Les conditions / modèles peuvent évoluer. Aucun passage automatique vers Paid. Le modèle de repli exact demandé était indisponible, donc le repli reste `none`.
10. **Signature / sauvegarde** : APK livré en debug pour essai ; signature parentale à créer pour les mises à jour durables. Les lectures et scores ne quittent pas la tablette ; effacer ses données les détruit.

Une migration future vers un endpoint Cloudflare authentifié pourrait offrir un déclenchement direct en un clic. Cette version fournit le chemin réel GitHub à deux étapes demandé, sans PAT ou secret partagé dans l’APK. Elle ne prétend pas qu’ouvrir une page déclenche le pipeline.
